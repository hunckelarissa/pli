## 0.1 Цель спецификации

Этот документ задаёт **нормативное** поведение компилятора и runtime для **нашего диалекта** классического PL/I с траекторией к Subset G.

Спецификация:

- описывает, что компилятор **должен** принимать, исполнять или отвергать;
- разделяет уровни **L0 / L1 / L2 / G-horizon**;
- не является учебником PL/I и не копирует IBM Enterprise.

Продуктовая рамка: ADR-0001. Инженерные открытые решения: [`../../decisions/OPEN.md`](../../decisions/OPEN.md).

### Статусы конструкций

| Статус | Значение |
|--------|----------|
| **must-run** | Парсится, семантически принимается, codegen+runtime дают определённое поведение |
| **must-parse** | Парсится; codegen может выдать not-implemented |
| **not-implemented** | Синтаксис/семантика известны, уровень ещё не дотягивает — **явная** ошибка |
| **out-of-scope** | Не цель диалекта (Enterprise и т.п.) |

Запрещено: принимать конструкцию в must-parse и молча генерировать неверный код.

## 0.3 Уровни языка (сводка)

| Уровень | Смысл |
|---------|--------|
| L0 | Существует: узкий exec + широкий классический parse |
| L1 | Утилиты: массивы, структуры, больше потока управления |
| L2 | Наследие: расширение к G по эталонам |
| G-horizon | Документированное пересечение с Subset G |
