# Формализованная спецификация — оглавление

**Статус:** каркас (глав ещё нет)  
**Назначение:** нормативное описание **нашего** диалекта и уровней L0→G.  
**Якоря литературы:** `docs/standards/`, `docs/classic/`, `docs/runtime/` (см. [`../README.md`](../README.md)).

Связь: [`../tz/TZ.md`](../tz/TZ.md), [`../decisions/OPEN.md`](../decisions/OPEN.md).

---

## Правила написания глав

1. Каждая нормативная глава: **Statement / Syntax / Constraints / Semantics / Implementation status** (`must-run` | `must-parse` | `not-implemented` | `out-of-scope`).  
2. Ссылка на литературу: G-ref / GC33-0009-4 / SC26-3114 / X3.53 — с пометкой, если отклоняемся.  
3. Не копировать целые тома в SPEC — **сжимать в закон диалекта**.  
4. Примеры кода в SPEC = будущие тесты (`must-run` / `must-parse`).
